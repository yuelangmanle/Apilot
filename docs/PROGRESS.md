## 三、核心设计（供后续维护者参考）

- **模型商店 / 广场**：列表阶段只用名字做启发式（要快），**真实文件与体积在详情页按需解析**；
  能力标签优先用"文件事实"（仓库里有 `mmproj*.gguf` 才算能看图）。
- **视觉投影（mmproj）是模型专用的**：靠"下载时记录的配对"或"名字匹配"挂载，
  否则一律不挂——挂错会让引擎拒绝加载并回退纯文本。App 内提供手动配对入口（名字匹配的排前）。
- **对话上下文**：分层管理——70% 水位零成本折叠（截短旧工具输出）→ 85%（可调）做
  **增量摘要**（与已有摘要合并去重），用户诉求原样保留；顶部显示占用百分比。
- **AI 插件**：统一 `@@TOOL` 协议（兼容 `@@工具名 {}` 与裸 JSON），本地与云端共用；
  每个分类独立开关并持久化；工具文档"一行式"注入（避免拖慢预填充）。
- **网关**：云端配置转发 或 本机模型离线推理；Android 前台服务保活。

# 附：本地推理提速的深度剖析（从根本出发）

> 结论先行：**手机端推理速度由"内存带宽"决定，不由"代码写得快不快"决定。**
> 想从根本提速，只有五条路，按性价比排序：

## 1. 让每次请求只算"新增的 token"（已启用，收益最大）
多轮对话里，前面所有内容的结果（KV cache）本可以复用，只算新输入。
llamadart 的 `GenerationParams.defaultReusePromptPrefix = true` 已默认开启，
**但前提是提示词前缀稳定**——v2.7.5 之前我们每轮都把"记忆检索结果"拼进
system 提示词，system 一变前缀全废，等于每轮从头算。现已改为**每会话只检索一次**。
预期收益：长对话的第 N 轮，预填充量从 O(N) 降到 O(1)，实测体感是"越聊越跟手"。

## 2. 让模型少算"每个 token"（GPU 卸载，已修）
逐 token 生成受**内存带宽**限制，GPU（Vulkan / Metal）的带宽远高于移动 CPU：
社区实测 Qwen3-0.6B 18→28 tok/s、Llama-3.2-3B 8→14 tok/s（约 1.5–2×）。
坑在于 llamadart 在 Android 把后端 `auto` 解析成 **CPU**，我们之前等于没开；
v2.7.5 起显式指定 Vulkan，并保留"失败自动回退 CPU"。
注意：安卓上 GPU 层数 > 0 时 flash-attention 会被自动关掉（库行为）。

## 3. 让硬件算得更快（编译期指令集 / 微内核，取决于依赖）
手机 SoC 普遍支持 `i8mm` / `dotprod` 指令，对 Q4/Q8 量化推理有 30–50% 提升；
KleidiAI 是 ARM 官方手写 GEMM/GEMV 微内核，也能显著加速。
**这两项在 llama.cpp 编译期决定**，我们能做的是：确认 llamadart 预编译库的
`GGML_CPU_ARM_ARCH` / KleidiAI 开关是否开启；若未开启，向上游提 issue 或
自建带这些开关的 native bundle（属于依赖侧工作，已记入待办）。

## 4. 线程数与 batch 调优（已暴露 UI）
- **生成**受内存带宽限制：大核 2–4 线程通常最优，线程过多反而因 cache 竞争变慢
  → 默认交自动，省电档压到 2。
- **预填充**受算力限制：线程越多越快 → `numberOfThreadsBatch` 取 `max(线程,4)`。
- `n_batch` 给到 512，首字延迟明显改善（v2.7.5 已设）。
- 内存 ≤4GB 的设备建议 2048 上下文 + Q4_K_M 或更小量化。

## 5. 投机解码（下一步的大招，预期 2×）
用一个小模型（0.5B 级）当"草稿"，大模型只做校验：社区实测 8B 模型
6→12 tok/s。适用条件苛刻（同族模型、显存够放下两个），适合做成高级选项。
llamadart 已暴露相关参数（`speculativeRollbackTokenMax` 等），落地成本中等。

## 不建议做的事（避免走弯路）
- **不要盲目调大上下文**：KV 内存线性增长，超过物理内存会触发换页，反而骤慢。
- **不要默认开 KV q8_0**：它省内存，但部分机型/后端上更慢（我们已改为默认关）。
- **不要指望"多开线程"通吃**：生成阶段线程过多会变慢，"越多越快"只适用于预填充。
- **不要在提示词里塞无关内容**：每多一个 token，每一轮都要重算（除非前缀稳定）。

## 当前默认参数（均衡档）
`线程 自动 · GPU Vulkan（失败回退 CPU）· FlashAttention 开 · KV f16 · batch 512 · 上下文 4096`
——以上每一项都能在对话页「参数 → 高级性能选项」里单独调，并一键重载生效。
